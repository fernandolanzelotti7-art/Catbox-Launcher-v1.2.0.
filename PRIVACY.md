# Política de Privacidade — Catbox Launcher

**Última atualização:** 17 de outubro de 2026

## 1. Sobre o projeto

O Catbox Launcher é um aplicativo independente para Windows que permite personalizar fontes e cursores do Roblox. O projeto não possui vínculo oficial com a Roblox Corporation.

## 2. Informações pessoais

O site do Catbox Launcher não exige cadastro ou login para acessar suas páginas ou baixar o aplicativo.

O projeto não solicita diretamente nome, endereço, telefone ou outras informações pessoais para realizar downloads.

## 3. Hospedagem e dados técnicos

O site utiliza a plataforma Vercel, que pode processar informações técnicas necessárias para disponibilizar o serviço, como endereços IP, informações do navegador e registros de acesso.

Os downloads também podem utilizar serviços do GitHub, sujeitos às práticas de privacidade da plataforma.

## 4. Funcionamento do aplicativo

O Catbox Launcher realiza operações locais no computador para aplicar personalizações e restaurar arquivos originais.

O aplicativo não foi desenvolvido para solicitar senhas ou credenciais da conta Roblox.

## 5. Serviços de terceiros

Para mais informações sobre os serviços utilizados, consulte:

- Vercel: https://vercel.com/legal/privacy-policy
- GitHub: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

## 6. Alterações

Esta política poderá ser atualizada caso novas funcionalidades sejam adicionadas ou as práticas de tratamento de dados sejam modificadas.
